# Jak spustit Početník v prohlížeči

GitHub Pages ještě nejsou zapnuté — proto `judikin.github.io` vrací 404
a CDN odkazy mohou zobrazit jen HTML kód místo aplikace.

## Zapnutí (jednou, 30 sekund)

1. Otevři: https://github.com/JudiKin/judita1/settings/pages
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `judita1` → složka **`/docs`**
4. Klikni **Save**
5. Po 1–2 minutách otevři: **https://judikin.github.io/judita1/**

Hotová aplikace se všemi 10 prostředími poběží na této adrese.
